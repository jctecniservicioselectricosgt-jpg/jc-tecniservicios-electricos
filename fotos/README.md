# Fotografías de proyectos de J&C

Sube aquí las fotografías reales de los trabajos realizados por J&C Tecniservicios Eléctricos.

## Organización sugerida

- `electricidad/` — tableros, instalaciones y canalizaciones.
- `cctv/` — cámaras y sistemas de videovigilancia.
- `redes/` — racks y cableado estructurado.
- `domotica/` — automatización y control.

## Recomendaciones

- Usa nombres sencillos, por ejemplo `tablero-electrico-01.jpg`.
- Prefiere JPG o WebP optimizados para web.
- Evita subir fotos demasiado pesadas.
- Sube únicamente imágenes que tengas autorización para publicar.

La carpeta aparece en GitHub al incluir este archivo. Puedes crear subcarpetas al subir la primera imagen de cada categoría.
